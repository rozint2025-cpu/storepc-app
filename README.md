# אפליקציית סטור פיסי – מדריך הקמה

החבילה כוללת שני חלקים:

| תיקייה | מה זה |
|---|---|
| `storepc_app/` | האפליקציה (Flutter) ל-Android ול-iPhone |
| `storepc-push/` | תוסף WordPress לשליחת התראות פוש (מתקינים ב-store-pc.co.il) |

## מה יש באפליקציה
- האתר store-pc.co.il בתוך האפליקציה. הקופה, החשבון והסליקה עובדים כרגיל.
- תפריט תחתון: **בית · מבצעים · עגלה · החשבון · עוד**
- תפריט "עוד" כולל:
  - ההתראות שלי (עם תג של הודעות שלא נקראו)
  - מועדון החברים, שירותי מעבדה, בקשה להצעת מחיר, צור קשר
  - כפתורי חיוג, וואטסאפ ומייל
  - מתג "התראות על מבצעים"
- התראות פוש עם תמונה. לחיצה על התראה פותחת את המוצר או העמוד באפליקציה.
- כשהאפליקציה פתוחה, התראה חדשה מופיעה כבאנר עם כפתור "לצפייה".
- מסך "אין חיבור לאינטרנט" עם כפתור "נסו שוב".
- כפתור "חזור" מנווט אחורה באתר, ולחיצה כפולה יוצאת מהאפליקציה.
- קישורים לוואטסאפ, פייסבוק, וייז וכדומה נפתחים באפליקציה המתאימה בטלפון.
- אפשר לשנות את כתובות הלשוניות ולהוסיף CSS שמוצג רק באפליקציה, מתוך הוורדפרס ובלי לבנות גרסה חדשה.

## מה יש בתוסף
- **שליחה ידנית:** כותרת, תוכן, תמונה מהספרייה וקישור. תצוגה מקדימה של ההתראה כמו בטלפון.
- **קהל יעד:** כולם, או רק מי שהפעיל התראות על מבצעים.
- **שליחה עכשיו או בזמן מתוזמן.** אפשר לבטל שליחה מתוזמנת.
- **שליחת בדיקה** לטלפון שלך בלבד.
- **כפתור "📲 שליחת פוש"** ברשימת המוצרים ובעמוד עריכת מוצר. ממלא כותרת, מחיר, תמונה וקישור אוטומטית.
- **אוטומציות:**
  - ירידת מחיר או כניסה למבצע (כולל מבצעים מתוזמנים של WooCommerce)
  - מוצר חדש (כבוי כברירת מחדל)
  - קופון חדש: מסמנים "שלח פוש" במסך עריכת הקופון
- **הגנות מהצפה:**
  - הנחה מינימלית באחוזים
  - לא שולחים פעמיים על אותו מוצר
  - מרווח מינימלי בין התראות אוטומטיות
  - השהיה לפני שליחה, כדי שיהיה זמן לתקן טעות
- **היסטוריה מלאה** וסטטיסטיקת מכשירים (כמה מכשירים רשומים וכמה פעילים, Android מול iPhone).

## שלב 1 – פרויקט Firebase (חינם)
1. נכנסים ל-https://console.firebase.google.com ויוצרים פרויקט חדש, למשל `storepc-app`.
2. **Project settings ← Service accounts ← Generate new private key.** יורד קובץ JSON. שומרים אותו בצד, צריך אותו לשלב 2.
3. **בשביל iPhone בלבד:**
   1. ב-Apple Developer יוצרים APNs Key (Certificates, IDs & Profiles ← Keys ← Apple Push Notifications service).
   2. ב-Firebase מעלים אותו: Project settings ← Cloud Messaging ← Apple app configuration.

## שלב 2 – התקנת התוסף בוורדפרס
1. **תוספים ← הוספה ← העלאת תוסף** ← בוחרים את `storepc-push.zip` ← הפעלה.
2. **פוש לאפליקציה ← הגדרות ואוטומציות:**
   1. מדביקים את כל תוכן קובץ ה-JSON משלב 1 ← שמירה ← "בדיקת חיבור".
   2. בודקים את כתובת ה"עגלה". כפתור העגלה באתר מוגדר כ-`#`, לכן כדאי לוודא שהכתובת פותחת את עמוד העגלה הנכון.
   3. מגדירים אוטומציות ותבניות הודעה.
3. **מומלץ:** WP-Cron רץ רק כשיש גלישה באתר. כדי שהתראות מתוזמנות יצאו בזמן:
   1. מוסיפים ל-`wp-config.php` את השורה `define('DISABLE_WP_CRON', true);`
   2. ב-cPanel ← Cron Jobs מוסיפים משימה כל 5 דקות:
      `wget -q -O - https://www.store-pc.co.il/wp-cron.php?doing_wp_cron >/dev/null 2>&1`
4. אם יש תוסף אבטחה או קאש (Wordfence, LiteSpeed וכו'), מוודאים שהנתיב `/wp-json/storepc-push/` לא חסום ולא נשמר בקאש.

> **אבטחה (לא חובה):** במקום להדביק את המפתח בהגדרות, אפשר לשמור את קובץ ה-JSON מחוץ ל-public_html ולהוסיף ל-wp-config.php:
> `define('STOREPC_PUSH_SERVICE_ACCOUNT_FILE', '/home/USER/storepc-firebase.json');`

## שלב 3 – בניית האפליקציה
צריך מחשב עם הכלים הבאים:
- [Flutter](https://docs.flutter.dev/get-started/install) (גרסה 3.24 ומעלה)
- Android Studio
- בשביל iPhone: Mac עם Xcode

```bash
cd storepc_app

# 1. יצירת קבצי הפלטפורמה החסרים (לא דורס את הקבצים הקיימים)
flutter create --org il.co --project-name storepc --platforms android,ios .

# 2. חיבור ל-Firebase (מתקינים פעם אחת: dart pub global activate flutterfire_cli)
flutterfire configure --project=storepc-app --platforms=android,ios

# 3. חבילות, אייקון ומסך פתיחה
flutter pub get
dart run flutter_launcher_icons
dart run flutter_native_splash:create

# 4. בדיקה על טלפון מחובר
flutter run
```

**לפני הבנייה:** מחליפים את `assets/icon.png` ואת `assets/splash_logo.png` בלוגו של סטור פיסי. מה שיש שם עכשיו הוא אייקון זמני בכחול.

### Android – בנייה לחנות Google Play
1. אם הבנייה נכשלת על `minSdk`, פותחים את `android/app/build.gradle.kts` ומשנים ל-`minSdk = 23`.
2. יוצרים מפתח חתימה ומגדירים אותו לפי [המדריך הרשמי](https://docs.flutter.dev/deployment/android#sign-the-app).
3. בונים: `flutter build appbundle --release`
4. מעלים את הקובץ `build/app/outputs/bundle/release/app-release.aab` ל-Google Play Console.

### iPhone – App Store
1. פותחים את `ios/Runner.xcworkspace` ב-Xcode.
2. **Signing & Capabilities:** מוסיפים **Push Notifications**, ו-**Background Modes** עם הסימון "Remote notifications".
3. בונים ומעלים: `flutter build ipa`, ואז Transporter או Xcode.
4. **תמונות בהתראות ב-iPhone (לא חובה):** צריך להוסיף Notification Service Extension לפי [התיעוד של Firebase](https://firebase.google.com/docs/cloud-messaging/ios/send-image). ב-Android תמונות עובדות בלי שום תוספת.

> **שימו לב לגבי App Store:** אפל דוחה לפעמים אפליקציות שהן "רק אתר בתוך אפליקציה" (סעיף 4.2). לאפליקציה הזו יש:
> - תפריט נייטיב
> - התראות פוש
> - מסך התראות
> - הגדרות מבצעים
>
> זה מחזק את הבקשה. כדאי לציין את זה בהערות לבודק בעת ההגשה. ב-Google Play אין בעיה כזו.

## בדיקה ראשונה מקצה לקצה
1. מתקינים את האפליקציה בטלפון ומאשרים קבלת התראות.
2. באפליקציה: **עוד ←** לחיצה ארוכה על "גרסה 1.0.0" **← העתקה**.
3. מדביקים את הטוקן בשדה **"טוקן מכשיר לבדיקות"** בהגדרות התוסף ושומרים.
4. במסך **שליחת התראה** לוחצים על **"שליחת בדיקה למכשיר שלי"**.

| כתובות הלשוניות | הגדרות התוסף ← "האפליקציה" (בלי גרסה חדשה) |
| להסתיר אלמנטים באפליקציה בלבד (פוטר, כפתור וואטסאפ צף) | הגדרות התוסף ← "CSS לאפליקציה בלבד" |

| שם האפליקציה בטלפון | `android:label` ב-AndroidManifest, ו-Display Name ב-Xcode |
